# Лабораторна робота 5: Заливка поля (Flood Fill)
Рівень 3
Варіант 1
## Умова завдання
Реалізувати алгоритм "Flood fill" (початкове заповнення), який визначає область, у яку входить певний вузол у багатовимірному масиві, та замінює колір цієї області на новий. Алгоритм шукає всі вузли в матриці, які з'єднані з початковим вузлом таким самим кольором (по вертикалі та горизонталі), та змінює їх на цільовий колір.

## Вхідні дані (`input.txt`)
* 1 рядок: висота та ширина поля (наприклад, `10,10`)
* 2 рядок: координати початкової точки `row,col` (наприклад, `3,9`)
* 3 рядок: колір заміни (наприклад, `'C'`)
* Наступні рядки: матриця кольорів у вигляді масивів символів.

## Вихідні дані (`output.txt`)
Матриця кольорів після виконання алгоритму заливки у тому ж форматі, що й вхідні дані.
